# Patagonia Grooming Co. · Barbería & Club · Neuquén

## Reserva de turnos
- El cliente elige servicio(s), barbero, día y horario, y completa sus datos.
- **WhatsApp:** envía el pedido con un mensaje ya armado al número de la barbería.
- **Google Calendar:** agrega el turno a su calendario con dirección y duración.

## Configuración
Todos los datos editables (número de WhatsApp, horarios, servicios, precios y barberos)
están en el bloque `CONFIG`, `SERVICES` y `BARBERS` al final de `index.html`.

## Publicación
Es un archivo HTML estático: funciona en GitHub Pages o en cualquier hosting sin build.
